Příručka je psaná primárně pro tři propojené obrazovky, na kterých stojí celý první dojem produktu:

0. Jak tuto příručku číst

Zdroje pravdy (v tomto pořadí):

  1. src/index.css — kanonické tokeny (:root) a veškerá Welcome + Convert logika.
  2. src/CitadelWheel.css — kolo, brána, pilulky, kompas.
  3. src/DashboardControl.css — tmavý „command deck" a karetní jazyk Convertu (--nd-*).
  4. docs/design-system.html — vygenerované vzorky z běžící aplikace.
  5. docs/noedis-screen-styles.md — krátký handoff pro stejné tři obrazovky.

Důležité upozornění k tokenům. Blok --noedis-* je v src/index.css:13–38 deklarovaný jako kanonická paleta, ale v kódu ho zatím nic nečte (0 použití var(--noedis-…)). Skutečné hodnoty jsou v pravidlech zapsané natvrdo. Ber proto tabulky níže jako popis stavu a --noedis-* jako cílový stav — při refaktoru se mají literály nahradit tokeny, ne tokeny přepsat na literály.

Naopak --nd-* (v .noedis-dashboard) je živý systém: var(--nd-cyan) se v DashboardControl.css používá 54×, --nd-card 15×. Tam tokeny používej vždy.

1.2 Písmo

Dvě rodiny, žádná třetí.

Display — Montserrat NOEDIS (lokální OTF, public/fonts/), fallback "Arial Black", sans-serif:

@font-face { font-family: "Montserrat NOEDIS"; src: url("/fonts/Montserrat-Black.otf") format("opentype");      font-weight: 900; font-display: swap; }
@font-face { font-family: "Montserrat NOEDIS"; src: url("/fonts/Montserrat-ExtraBold.otf") format("opentype"); font-weight: 800; font-display: swap; }

Použití: nadpisy (h1), motto, číselné údaje, názvy karet převodů.

UI — systémový sans, nikdy se nenačítá:

font-family: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;

Použití: vše ostatní — labely, tlačítka, tabulky, monospace metadata (ui-monospace).

Mikro-typografie rozhraní. NOEDIS má výrazný rys: široce prostrkané verzállky. Drž se vzorce font-weight: 850–950, letter-spacing: .12–.4em, text-transform: uppercase, font-size: 6–11px pro labely a eyebrow texty.

1.3 Tón a principy

  1. Barva vždycky něco znamená. Nikdy není dekorace. Zóna určuje prstenec, převod svou kartu, stav mění jen jas a krytí.
  2. Jeden dominantní akcent na komponentu. Druhá nasycená barva patří pouze stavu nebo akci.
  3. Sklo místo plochy. Světlé vrstvy #ffffff04–#ffffff20 přes noční podklad.
  4. Pohyb odpovídá na akci. Nic se nehýbe samo; vždy existuje prefers-reduced-motion větev.
  5. Text na tmavé je vždy světlý. Tlumená barva nikdy nenese jediný label akce.

3. Gradienty

Gradient nese hloubku nebo aktivaci. Nikdy není dekorativní náhoda. Vždy používej pojmenovanou rodinu, ne nový gradient s mírně jinými stopy.

3.1 Modrá–fialová — primární gateway

--noedis-gradient-blue-purple: linear-gradient(115deg, #507cff 0%, #8a54ef 52%, #35c9ed 100%);

Toto je odpočinkový stav primárního vstupu. Vykresluje hlavní CTA ENTER NOW (.welcome-enter, index.css:2522) a je to vizuální podpis „vstupu do NOEDIS".

Související, ale samostatný odstín pro vytvoření identity:

background: linear-gradient(110deg, #7555d9, #5f50d8 52%, #388edc);  /* .welcome-auth-create */

3.2 Oranžová–červená — aktivace

--noedis-gradient-orange-red: linear-gradient(115deg, #ff295f 0%, #ff5737 48%, #ffb43d 100%);

Toto je aktivační signál, ne klidová barva. Na Welcome je schovaný v .welcome-enter::before s opacity: 0 a rozsvítí se až při :hover (index.css:2523, :2532). Znamená „gateway se právě aktivuje".

Nikdy nedělej ENTER NOW oranžové v klidu. Oranžovo-červená je odměna za akci, ne výchozí stav.

3.3 Zelená — domov a earned

--noedis-gradient-home: linear-gradient(115deg, #159664, #2ab77f);

Navigační a „zdravá" akce: GO HOME (.dashboard-enter, index.css:1547). Nesmí nikdy zdědit barvu aktivní měny — vede na Home Dashboard, ne na další převod.
